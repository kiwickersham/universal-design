What Is This Site?

This site is intended as a basic overview of the what, how, and why of universal design for web developers.

The What? page defines the concept of universal design, including history and basic principles. The Why? page discusses reasons to take a universal design approach to your own projects. The How? page gives an overview of some of best practices for universal design and lists some resources for evaluating designs.

All three pages link to helpful outside resources, but if you're still interested in learning more, here are some sites that may interest you:

  • W3C Accessibility Fundamentals
  • W3C Developer Resources
  • MDN Accessibility Docs
  • RL Mace Universal Design Institute
